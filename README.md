# RetroPortDB

RetroPortDB is a curated, static database of modern native ports, decompilations,
recompilations, reverse-engineered engines, and reimplementations of classic games.
It is not an emulator catalogue and never hosts game files or copyrighted assets.

## Development

```bash
npm install
npm run dev
npm run validate
npm run test
npm run build
```

See [the V0.1 implementation plan](docs/implementation-plan-v0.1.md),
