# Contributing

Thank you for improving RetroPortDB. Contributions describe software projects,
not game downloads. Do not add ROM, BIOS, or piracy links.

## Add a project

1. Add or update its separate game and project YAML records.
2. Use stable IDs and update both sides of the relationship.
3. Link the official upstream repository or website.
4. Provide evidence for maturity or compatibility claims; leave unknown claims as
   `unknown`.
5. Run `npm run validate`, `npm run test`, and `npm run build`.

Discovery candidates are leads only. They must be researched and converted into
curated records manually; never promote a candidate without evidence.
